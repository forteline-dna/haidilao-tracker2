# 3. 설계 조정 사항
## 식탁 및 천장 조명 배치
- 식탁·배기관·천장 조명 위치는 식탁 중심 기준 일직선 정렬
- 천장 조형: S자 형태로 변경, 4인 테이블 기준 10cm 낮춤

## 개인실 (VIP룸)
- 벽·문 개구부 크기 통일, 슬라이딩 도어 규격 일치화
- VIP7 개인실 – 벽 튀어나온 부분 정렬 필요
- 개인실 최저 높이: 2350mm → 2400mm로 높이는 방향 검토

## 화장실
- 걸레받이(踢脚線)를 벽면과 평평하게 마감
- 방화판 마감 스트립(MT 02-T0505) 수량 집계 후 발주
- 위생도기: 샘플 확인 후 설치 높이는 입면도 기준

## 소방 설비
- 소화 유출 밸브: 스퀴브 룸으로 이동 여부 소방 당국 확인 후 다음 주 수요일까지 회신
- 소화기 위치: 소방 도면 완성 후 결정, 밀폐 설치 방식 적용
- 소화전·설비: 고전압실·저전압실 외부에 노출 배치

# 4. 자재 조달
- 가구류: 공급사가 목록·심화 도면 정리 → 현장 크기 확인 후 이메일로 발주
- 기초 자재: 돈공 서명 확인, 외관 스타일은 매장 확인 → 5월 30일까지 샘플 확정
- T5, MT 02-T0505(방화판 마감 스트립) 수량 집계 → 익일까지 완료
- 변경 협상(增減項): 사전에 변경 서식 작성 후 비용 심사를 거쳐 집행
- 모든 발주는 이메일 기준, 변경 사항도 반드시 이메일로 동기화

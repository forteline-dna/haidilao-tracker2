   • 천장 점검 7/20 시행 예정 — 7/16 웨이공 확인 후 7/20 최종 천장 점검 진행
   • 天花验收预计7/20进行 — 7/16魏工确认后，7/20进行最终天花验收
   • 천장 점검 전 룸 에어컨 응축수관 현장 확인 필요
   • 天花验收前需现场确认包间空调冷凝水管

2. 주요 논의 사항 / 主要讨论事项
   • 소변기 하자 관련 — 건물 측 정화조 통기관 있음 확인
   • 小便器问题 — 已确认物业有通气管
   • 스프링클러 가지관 PVC 배관 인증서 및 관련 법령 — 라크방(飞书)에 공유 완료
   • 喷淋支管PVC配管认证书及相关法规 — 已发至飞书群
   • 주방 화구 사용 위치 소방 확인 — 최종 소방 도면 업데이트 중 (화구 2개소: 직원 식사용)
   • 厨房炉头使用位置消防确认 — 最终消防图纸更新中（2处：员工餐区）
   • 주방 후드 위치 확인 — 총 4개소
   • 确认后厨排烟罩位置 — 共4处
   • 조명 도면 확인 — 안산점 방문하여 조도 확인 예정
   • 确认照明图纸 — 计划前往安山店确认照度

3. 결정 사항 / 决定事项
   • 온수보일러 48,000kcal 사양으로 결정
   • 确定热水器采用48,000kcal规格
   • 룸 유리 샘플 3종 다음 주 확인 예정, 천정높이 변경으로 인해 유리 프레임 100mm 부족 — 하부 턱 추가로 해결
   • 包间玻璃样品3种下周确认，因天花高度抬高，玻璃框架不足100mm — 计划通过增加下部挡边解决
   • 에어컨 디퓨저 샘플 견적서 송부 예정
   • 空调出风口样品报价将另行发送
   • 룸 아트월 샘플 다음 주 제공 예정
   • 包间挂画样品下周提供
